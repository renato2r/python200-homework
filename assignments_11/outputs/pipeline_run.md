# Capstone Reflection

The pipeline did not run cleanly on the first and second due to local Azure authentication failures with DefaultAzureCredential and initial Prefect object serialization errors. I resolved these issues by initializing the OpenAI client directly inside the task and switching to a secure Azure Connection String for local development. Once these adjustments were made, the Prefect UI loaded perfectly on localhost:4200 and displayed a clear hierarchical tree of successful task completions. The dashboard confirmed that no manual retries were triggered, as the API extraction and LLM transformations executed flawlessly after the environment was stabilized. If deploying this pipeline on a daily production schedule, I would add an automated email or Slack alert notification hook to instantly flag any API connection failures.
